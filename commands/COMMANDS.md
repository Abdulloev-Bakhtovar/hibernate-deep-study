# Команды учебного агента

Команды — это текстовый протокол. Если среда не поддерживает slash-команды нативно, введи команду в чат; агент должен открыть соответствующий файл и выполнить инструкцию.

| Команда | Файл | Назначение |
|---|---|---|
| `/start` | `commands/start.md` | Восстановить контекст из Git и начать текущую работу |
| `/next` | `commands/next.md` | Продолжить ровно со следующего незавершённого шага |
| `/lesson <ID>` | `commands/lesson.md` | Открыть/провести конкретный урок |
| `/review` | `commands/review.md` | Проверить присланный код/результат |
| `/trace <API/class/method>` | `commands/trace.md` | Проследить реализацию в Hibernate source |
| `/explain <topic>` | `commands/explain.md` | Объяснить одну тему без продвижения статуса |
| `/quiz` | `commands/quiz.md` | Проверить понимание текущей/закрытой темы |
| `/checkpoint` | `commands/checkpoint.md` | Сохранить состояние, прогресс и результат сессии |
| `/handoff` | `commands/handoff.md` | Подготовить передачу следующему агенту |
| `/status` | `commands/status.md` | Кратко показать текущее состояние курса |
| `/help` | `commands/help.md` | Показать команды и workflow |
| `/reopen <ID>` | `commands/reopen.md` | Вернуть закрытую тему в работу при обнаружении пробела |

## Важное правило

`/checkpoint` и `/handoff` должны обновлять файлы в рабочем репозитории, а не только печатать резюме в чат. Если агент не имеет доступа на запись, он обязан выдать готовые фрагменты/патч для вставки.
