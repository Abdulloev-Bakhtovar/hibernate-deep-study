# /checkpoint

Сохрани текущее состояние в Git-файлы проекта.

1. Зафиксируй, что ученик реально сделал: файлы, код, команды, тесты и наблюдаемые результаты.
2. Отдели `DONE`, `IN_PROGRESS`, `NOT_STARTED`; не повышай статус без критериев из `docs/COURSE_RULES.md`.
3. Обнови `state/CURRENT.md` с точной следующей задачей.
4. Обнови `state/PROGRESS.md`.
5. Обнови `state/HANDOFF.md` коротким контекстом для нового агента.
6. Добавь запись в `state/SESSION_LOG.md` (дата, ID урока, результат, commit hash если известен).
7. При архитектурном решении обнови `state/DECISIONS.md`.
8. Не копируй в handoff длинные фрагменты кода; укажи пути к файлам.
9. Не коммить/пушь автоматически. В конце покажи, какие файлы изменены, и предложи Git-команды.

Если фактического прогресса нет, не придумывай его — зафиксируй только статус.
