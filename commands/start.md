# /start

1. Прочитай `AGENTS.md`, `state/HANDOFF.md`, `state/CURRENT.md`, `state/PROGRESS.md`, `docs/COURSE_RULES.md`.
2. Прочитай только активный урок и relevant files.
3. Не загружай весь `SESSION_LOG.md` и `history/` без необходимости.
4. Кратко восстанови статус: completed prerequisites, current Hibernate phase, exact next task, pinned versions.
5. Не спрашивай повторно известные детали.
6. Продолжи активный урок. Если курс ещё не начинался — начни `H00`.
