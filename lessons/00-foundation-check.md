# H00-PRE — Проверка предпосылок (без повторного курса)

- Статус: `DONE_BY_HISTORY`.
- Это не урок Hibernate и не требует повторного прохождения.

## Считается известным

- PostgreSQL и базовый SQL.
- JDBC API и путь Java → JDBC driver → PostgreSQL.
- PreparedStatement/ResultSet.
- Транзакции, уровни изоляции, MVCC, `xmin`/`xmax`, VACUUM.
- Connection pool/HikariCP.
- Spring JDBC `JdbcTemplate`.

## Правило

Если в ходе Hibernate-урока выяснится пробел, агент должен объяснить только конкретную необходимую часть и вернуться к Hibernate. Не открывать повторно общий курс PostgreSQL/JDBC.
