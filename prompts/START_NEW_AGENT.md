# Prompt для запуска нового агента

Прочитай файлы проекта в порядке, заданном `AGENTS.md`. Не проси меня повторно объяснять мой уровень и историю: они сохранены в Git.

Текущий курс: Hibernate ORM с нуля. PostgreSQL, JDBC и JdbcTemplate уже пройдены. Все предыдущие обсуждения Hibernate считаются незачтёнными. Мы не продолжаем старый MiniEntityManager; начинаем по roadmap с H00.

Твоя первая задача:
1. Кратко сообщи, что ты восстановил контекст из файлов.
2. Назови зафиксированные версии/ограничения и что уже пройдено до Hibernate.
3. Назови текущую фазу и следующий урок из `state/CURRENT.md`.
4. Не повторяй весь план и не задавай вопросы, ответы на которые уже записаны.
5. Начни H00 по `docs/TEACHING_PROTOCOL.md`: объясни карту Hibernate/Jakarta Persistence/native API и предложи первую небольшую проверку понимания.
6. Не подключай Spring и не выдавай готовый учебный проект вместо практики.

Если файлы противоречат друг другу, не угадывай: перечисли конфликт, предложи точечное исправление и зафиксируй решение после согласования.
