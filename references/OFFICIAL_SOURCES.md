# Официальные источники

Зафиксированные ссылки для версии 7.4:

- Hibernate ORM releases: https://hibernate.org/orm/releases/
- Hibernate ORM 7.4 release page: https://hibernate.org/orm/releases/7.4/
- Hibernate ORM documentation 7.4: https://hibernate.org/orm/documentation/7.4/
- Hibernate 7 Short Guide (актуальная стабильная 7.4.17.Final): https://docs.hibernate.org/stable/orm/introduction/html_single/
- Hibernate User Guide: https://docs.hibernate.org/stable/orm/userguide/html_single/
- Hibernate Quickstart: https://docs.hibernate.org/stable/orm/quickstart/html_single/
- Hibernate ORM source repository: https://github.com/hibernate/hibernate-orm

Важно: для исходников использовать релизный tag `7.4.17` (или точное имя тега, опубликованное в GitHub), не ветку `main`.

На 2026-11-23 официальный сайт указывает `7.4.17.Final` от 2026-11-19 как latest stable, а `8.0.0.CR1` от 2026-11-12 как development. Совместимость 7.4: Java 17/21/25/26; Jakarta Persistence 3.2.
