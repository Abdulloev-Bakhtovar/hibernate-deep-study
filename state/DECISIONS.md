# Журнал архитектурных и учебных решений

## D-001 — Начать Hibernate обучение заново

- Дата: 2026-11-23.
- Решение: все предыдущие обсуждения и эксперименты по Hibernate считать незачтёнными. Прогресс Hibernate в этом репозитории начинается с 0%.
- Причина: требуется устойчивый, последовательный курс с переносом состояния между локальными AI-агентами через Git.

## D-002 — Не повторять PostgreSQL/JDBC/JdbcTemplate

- Дата: 2026-11-23.
- Решение: PostgreSQL, JDBC, транзакции/MVCC, HikariCP и Spring JDBC `JdbcTemplate` считаются завершёнными предпосылками.
- Причина: эти темы уже были изучены ранее; курс должен сосредоточиться на Hibernate.

## D-003 — Версия Hibernate

- Дата: 2026-11-23.
- Решение: закрепить Hibernate ORM `7.4.17.Final`, Java 17.
- Причина: 7.4.17.Final обозначен официальным сайтом как latest stable на дату фиксации; 8.0.0.CR1 обозначен как development. Java 17 поддерживается веткой 7.4.
- Источник: `docs/SOURCE_POLICY.md`.

## D-004 — Spring отложить

- Дата: 2026-11-23.
- Решение: не использовать Spring ORM/Spring Data до завершения Hibernate Core и Jakarta Persistence.
- Причина: сначала нужно понять сам ORM и стандартный контракт, только затем изучать интеграционные уровни.
